▲ ai2vpn

Your AI accounts, behind your VPN, as an OpenAI-compatible API.

▲ ai2vpn

Accounts

Each account is a real browser profile inside the container. Sign in to your ChatGPT / Claude / Gemini / … account once (email & password, or in the remote browser), then call it through its own API key.

No accounts yet.

VPN

All traffic from the browsers in this container leaves through the VPN. The web UI and API stay reachable on the host port.

Connection

VPN mode is fixed by the VPN_MODE environment variable.
NordLynx generator

Creates a WireGuard config from your NordVPN access token.

Run this container with network_mode: service:gluetun (see docker-compose.gluetun.yml) or on a host that is already on a VPN. ai2vpn will not touch the network; it only shows the exit IP.

Sandbox

          
A separate container with Claude Code, Codex and Gemini CLI. It shares ai2vpn's network, so everything it does goes through the VPN. Your files are in ./workspace on the host.

        

        

          Open in new tab
          
        

      

      
The sandbox container isn't running. Start it with docker compose up -d --build sandbox.

      

        

        

          
Log in to the CLIs

          
    
            
  1. Claude Code: type claude and choose your Claude subscription (Pro/Max). Open the link it shows, sign in, then paste the code back into the terminal.
    2. 
            
  2. Codex: type codex and choose Sign in with ChatGPT. Its link sends you back to localhost:1455, so open it in the login browser below (it shares the sandbox's network).
    3. 
            
  3. Gemini CLI: type gemini and choose Login with Google. Use the login browser for its link as well.
    4.
